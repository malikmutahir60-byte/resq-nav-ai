# AI Usage Report

RESQ-NAV AI is being developed using an AI-first workflow in accordance with the hackathon requirements.

## AI Tools Used

| Tool | Purpose |
|---|---|
| ChatGPT | Architecture, coding assistance, debugging, documentation |
| AI coding assistant | Code generation and refactoring |
| AI design tools | UI/UX ideation |
| AI research assistance | Technical research and analysis |

## Development Areas

### Product Design
AI assisted with feature prioritization and system architecture.

### Software Development
AI assisted in generating and refining application code.

### Algorithms
AI assisted with BFS, A* and risk-aware planning implementations.

### Testing
AI assisted in generating test cases and identifying edge cases.

### Documentation
AI assisted in technical documentation and presentation material.

## Human Validation

All AI-generated outputs must be reviewed, tested and modified by the team before inclusion in the project.
