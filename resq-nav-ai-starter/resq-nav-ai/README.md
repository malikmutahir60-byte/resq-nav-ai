# RESQ-NAV AI 🚁

### When GPS fails, intelligence takes over.

RESQ-NAV AI is an AI-powered disaster search-and-rescue intelligence platform designed for GPS-denied and infrastructure-damaged environments.

## 🚨 Problem

During disasters such as building collapses, floods and landslides, rescue teams may face unreliable GPS, damaged communication infrastructure, blocked routes and dangerous environments.

Finding survivors while simultaneously planning safe routes can expose rescuers to unnecessary risk.

## 💡 Our Solution

RESQ-NAV AI combines:

- AI-based survivor detection
- Disaster environment mapping
- BFS-based systematic search
- A* path planning
- Risk-aware navigation
- Rescue priority analysis
- AI Rescue Copilot
- Dynamic route recalculation

The system provides decision support to rescue operators while keeping humans in control of critical decisions.

## 🎯 MVP

Our prototype demonstrates an autonomous UAV operating inside a simulated disaster environment where GPS is unavailable.

The system can:

1. Detect possible survivors
2. Identify obstacles
3. Build an environment map
4. Search the environment
5. Calculate routes using BFS and A*
6. Select safer routes using risk-aware planning
7. Prioritize potential rescue targets
8. Recalculate routes when the environment changes
9. Explain decisions using an AI Rescue Copilot

## 🧠 AI Architecture

```text
Sensor / Camera Data
        ↓
AI Perception
        ↓
Environment Map
        ↓
Risk Analysis
        ↓
BFS / A* Planner
        ↓
Rescue Priority
        ↓
AI Rescue Copilot
        ↓
Human Operator
```
