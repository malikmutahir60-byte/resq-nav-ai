# AI Architecture

RESQ-NAV AI follows an AI-first development approach.

## AI Components

### Computer Vision
Used for possible survivor and obstacle detection.

### Search Intelligence
BFS provides systematic exploration.

### Informed Planning
A* provides efficient path planning.

### Risk-Aware Planning
Environmental risk is incorporated into route selection.

### AI Rescue Copilot
An LLM interprets structured mission information and provides explanations to the human operator.

## Human-in-the-Loop

The AI system provides recommendations and explanations. Critical decisions remain under human supervision.
